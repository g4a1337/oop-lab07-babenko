## Завдання

Варіант 1. Реалізувати функцію обчислення площі трикутника за трьома сторонами. Перевіряти параметри та генерувати відповідні винятки. Показати чотири форми функції: без специфікації винятків, з throw(), зі специфікацією стандартного винятку та зі специфікацією власного винятку. Власний виняток реалізувати як порожній клас, незалежний клас із полями-параметрами та нащадок стандартного винятку з полями. У головній функції продемонструвати обробку передбачених помилок. Сформувати звіт.

## Файли

- `main.cpp` — вихідний код.

- `expected_output.txt` — фактичний вивід перевіреного запуску.

## Збирання

Потрібні GCC/MinGW з підтримкою C++14 та PowerShell. Перевірено GCC 16.2.0 (w64devkit). Запускайте команди в каталозі цієї лабораторної роботи. Для всіх команд `g++` і `ar` мають належати до одного комплекту MinGW.

Якщо каталог `bin` компілятора вже додано до `PATH`:

```powershell
.\build.ps1
```

Або передайте шлях до власного каталогу `bin` компілятора:

```powershell
.\build.ps1 -CompilerDirectory '..\mingw64\bin'
```

Окремі команди збірки:

```text
g++ -std=c++14 -Wall -Wextra -pedantic main.cpp -o main.exe
```

Стандарт `-std=c++14` потрібний для навчальної демонстрації специфікацій `throw(...)`. Попередження про їх застарілість очікувані; у C++17 та новіших стандартах ці специфікації вилучено.

## Запуск і перевірка

Для інтерактивного запуску:

```powershell
.\main.exe
```

Для повторення перевіреного запуску та порівняння рядків із записаним результатом:

```powershell
cmd /c ".\main.exe > actual_output.txt"
if ($LASTEXITCODE -ne 0) { throw 'Program failed' }
Compare-Object (Get-Content .\expected_output.txt) (Get-Content .\actual_output.txt)
```

Порожній результат `Compare-Object` означає збіг рядків. Каталог `bin` MinGW залиште в `PATH`, щоб Windows могла знайти потрібні бібліотеки середовища виконання. Програма перевіряє результати та завершується з кодом `0` після успішного виконання.

Очікувані перевірки:

- Усі шість реалізацій для сторін 3, 4, 5 повертають площу 6.00.
- Без специфікації перехоплено std::invalid_argument для сторін (0,3,4), (−1,3,4), (1,2,3) та нескінченної сторони.
- Функція зі специфікацією throw(std::invalid_argument) передає main помилку нерівності трикутника.
- Версія throw() обробляє помилку всередині та повертає маркер −1.00 без виходу винятку.
- У main перехоплено EmptyError, ParameterError і TriangleError; у двох останніх збережено сторони 1, 2, 3.
- Програма друкує Self-checks: PASS і завершується з кодом 0.
